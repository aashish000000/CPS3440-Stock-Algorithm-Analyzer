Stock Market Algorithm Analyzer

CPS 3440 group project: comparing algorithms for finding the best buy/sell window and the top movers in real S&P 500 data.

Team: Aashish Joshi, Aron Dardouri, Bhartendra Kumar Mandal, Brian Lucero

GitHub repository

Algorithms

The best buy/sell window is the maximum subarray of daily adjusted-close changes. Three algorithms solve that problem: brute force (O(n²)), divide and conquer (O(n log n)), and Kadane's scan (O(n)).

Top movers ranks stocks by buy-and-hold return. Three algorithms select the top K: a full sort (O(n log n)), a binary heap of size K (O(n log k)), and quickselect (O(n) average).
