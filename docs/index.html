Stock Market Algorithm Analyzer

How fast can we find the best time to buy and sell in millions of rows of real stock prices? We implement and benchmark three algorithms to find out.

ProblemDatasetAlgorithmsResultsTeamResources

The Problem

Given daily prices, which contiguous window of days gives the largest total gain (the maximum subarray problem), and which days had the biggest moves (Top-K)? A slow method works on a year of data but fails on millions of rows. This is algorithm analysis, not price prediction.

Dataset

S&P 500 OHLCV Stock Data from Kaggle: about 2.7 million daily rows for roughly 470 companies (2000 to 2026).

Our Solution

A Python command-line tool and benchmark suite that runs each algorithm on the same data and reports the answer and the runtime. Demo coming soon.

Algorithms and Complexity
