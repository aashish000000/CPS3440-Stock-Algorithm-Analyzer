# Data

Dataset: [S&P 500 Historical Data (Kaggle, jacksaleeby)](https://www.kaggle.com/datasets/jacksaleeby/s-and-p500-historical-data).

1. Download the CSV from Kaggle.
2. Save it as `data/SP500_Historical_Data.csv`.

Columns: `Ticker`, `Date`, `Open`, `High`, `Low`, `Close`, `Adj Close`, `Volume`. The file is large (about 143 MB), so it is gitignored. A small offline sample for tests is `tests/fixtures/sample.csv`.
